This file lists all changes in both the English and International master text directories.
I'll probably need a better formatting system for this in the future - but currently, all
text changes are stored here.  If a language isn't affected by a fix, the language tag
isn't listed below.

Unofficial fixes are noted below with a bullet (•).  Bugfixes by Petroglyph will be noted
in the subsequent hotfix's changelog; changes made by the Unofficial Patch will be removed
in tandem and mentioned in the next update.

When fixed, bugs introduced by the Unofficial Patch are included in the next hotfix under
the "UFCP" header and retroactively edited in the changelog.

Dates, grammar, and times are always in American format.
(i.e. "10-24-2006" = October 24th, 2006, "color" > "colour," "1:52 PM" > "13:52 EST.")

All entries have tags that are accurate to their GitHub report page's URL. Insert the report
number into the below URL to see the original report.

International:
• Various instances of tooltips ending without periods in the English, French, Italian, Polish and Russian localizations have been corrected.  This change remains unmarked in this file to avoid conflicts with changes on the same text keys.
• Various instances of German unit classes, inconsistently, being the unabbreviated "Klassifizierung:" instead of "Klasse:" have been fixed.  This change remains unmarked in this file to avoid conflicts with changes on the same text keys.
• English, French, German and Italian localizations infrequently referred to the Keldabe-class Battleship as the "Kedalbe," an old spelling from '80s Star Wars material.  All instances of "Kedalbe" have been swapped out for "Keldabe."  This change remains unmarked in this file to avoid conflicts with changes on the same text keys. (BUG #236)
• All localizations (except Italian) of Bossk and Jabba the Hutt's dialogue sometimes didn't follow the general trend of alien language dialogue, and wasn't prefixed with "(Translated)" like Jabba's dialogue, or his own dialogue in the campaign.  The prefix has been added and remains unmarked in this file to avoid conflicts with changes on the same text keys. (BUG #362)
• English, French, Italian, Polish, Russian and Spanish localizations inconsistently used a special "…" (elipsis) character, or "..." (three periods).  The ellipses character is harder to read at high resolutions, and back-and-forth use of ellipses and periods caused spacing issues (f.e. as "to the Empire… .").  All ellipses have been swapped out for three periods and remains unmarked in this file to avoid conflicts with changes on the same text keys. (BUG #211)

• Various instances of "Tie" (f.e., as "Tie Mauler") have been capitalized properly to "TIE."  This change remains unmarked in this file to avoid conflicts with changes on the same text keys. (International translations did not suffer this issue.) (BUG #859)
• The vast majority of dialogue is double-spaced in EaW (and mostly in FoC), however, dialogue during general mission briefings, the Consortium's prologue, campaign and corruption missions weren't.  Double-spacing has been rectified all-around (including instances of triple-spacing), and remains unmarked in this file to avoid conflicts with changes on the same text keys. (International translations did not suffer this issue, as all dialogue is single-spaced.) (BUG #208)

• Multiple instances of "[Character] Must Survive." have been de-capitalized.  Various text strings alternated between the two capitalizations, when the most consistent capitalization was "[Character] must survive."  International languages did not suffer this problem. (BUG #561)
• A handful of text strings that used colons (:), unlike other strings in FoC, had a space before their usage (f.e., "Windows Firewall :"), which has now been corrected.  This change remains unmarked in this file to avoid conflicts with changes on the same text keys. (International translations did not suffer this issue, as this was either intentional [in languages like French, where spaced punctuation is standard] or not applicable.)

This change remains unmarked in this file to avoid conflicts with changes on the same text keys. (International translations did not suffer this issue.)
